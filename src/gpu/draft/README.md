# Archived GPU experiments

These shaders are historical prototypes, not built or dispatched by the
library. `hierarchical.slang` and `hierarchical_fused.slang` are the early
hierarchical experiments referenced in `docs/gpu-notes.md`. Production uses
`tierb.slang`, `coarse_tile.slang`, `series_forward.slang` and `pack_coarse.slang`
in the parent directory, built together by `tools/build_spirv.py`.
